هذا إصدار أولي بسيط يعمل دون إنترنت ويحوّل مجموعة من الكلمات والعبارات الشائعة.
لإخراج APK:
1) افتح المشروع في Android Studio.
2) انتظر Gradle Sync.
3) Build > Build APK(s).
4) ستجد الملف داخل app/build/outputs/apk/debug/

لتحويله إلى كيبورد حقيقي أو إضافة ذكاء اصطناعي للتحويل الحر، يحتاج المشروع إلى تطوير إضافي.
